## Явная трактовка противоречия о фоне

ТЗ требует загрузки палитры и автоматической перекраски, но примеры запрещают
менять цветовую схему фона. В реализации сохранена структура схемы: фон использует
только три background-роли, а не цвета objects. Пользовательская палитра заменяет
значения этих ролей, не меняя геометрию/детали. Это трактовка разработчика,
не подтверждённое разъяснение работодателя. Если подразумевается полный запрет
перекраски фона, нужно отключить применение пользовательских background-цветов
к фону; исходные три схемы уже поддерживаются отдельно.

## Границы решения

- Отбор по свободной метафоре требует ключа и доступной квоты Groq. Без ключа
  предусмотрены ручной режим и честно обозначенные готовые примеры.
- JSON-палитра выбрана как простой документированный формат; импорт ASE/ACO
  не заявляется. Загрузка произвольных SVG не требуется при подготовленной библиотеке.
- Автоматическая раскладка основана на правилах; нет гарантии художественно
  оптимального результата для любой метафоры. Для этого есть ручная корректировка.
- Проверка векторности и редактирования выполнена программно и рендерером;
  отдельный импорт в Figma не подтверждён. Это не заявляется как выполненная проверка.
- Публичный хостинг не обязателен по ТЗ и не настроен. В комплекте запускаемый проект.
