# Структура репозитория

Актуальная структура и запуск описаны в [README](../README.md), потоки данных —
в [архитектуре](architecture.md).

- `app/main.py` — HTTP API, модели сцены, палитры, адаптация и SVG-экспорт.
- `app/layout.py` — выразительная автоматическая раскладка.
- `app/ai.py` — Groq, проверка ответов, кеш и ограничения.
- `web/app.js` — базовый редактор; `web/editor.js` — история, проекты, примеры и палитры.
- `assets/` — оригинальные SVG и каталог. Их хранение в Git необходимо для запуска.
- `examples/` — три воспроизводимые композиции и палитра.
- `tests/` — автоматические проверки, не требующие ключа.
- `.github/workflows/tests.yml` — запуск проверок в GitHub Actions.

Git подключён к `git@github.com:condorTes/ochen-illustration-builder.git` по SSH.
Основная ветка — `main`. Коммиты отражают этапы разработки; история не переписывалась.

`.gitignore` исключает `.env`, окружения, установленные библиотеки, временные экспорты,
инструменты разбора видео и проверочные скриншоты. В Git находятся только шаблон
настроек `.env.example` и файлы зависимостей. `.gitattributes` сохраняет байты SVG.
