# Использование ИИ

| Инструмент | Для чего использовался |
| --- | --- |
| OpenAI Codex | Совместный разбор ТЗ, проектирование, написание Python/JS/CSS, тестов и документации, анализ экспортов, проверка интерфейса и работа с Git |
| Groq API, `openai/gpt-oss-20b` по умолчанию | Функция самого сервиса: превращает метафору в список существующих id, состояния и объяснение выбора |

Модель Groq можно заменить через `GROQ_MODEL`. Проверенная интеграция опирается
на [официальную документацию](https://console.groq.com/docs/openai).

ИИ не генерировал иллюстрации и не дорисовывал предметы. Все изображения происходят
из предоставленной библиотеки. Код компоновки, проверки и экспорта детерминирован,
модель не управляет геометрией SVG.

Автор предоставлял исходники, выбирал решения, проверял приложение и присылал
видеозаписи обратной связи. Codex использовался как помощник в разработке и проверке.
PyAV, Pillow и Sharp — обычные технические библиотеки анализа/рендеринга, не AI-модели.

Для проверки нельзя полагаться только на ответ ИИ: исходные контуры и хеши,
цветовые ограничения и структура экспорта проверяются отдельными тестами.
