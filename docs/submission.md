# Текст для отправки работодателю

Здравствуйте! Подготовил тестовое задание — конструктор векторных иллюстраций.

Репозиторий: https://github.com/condorTes/ochen-illustration-builder

Реализованы два сценария: подбор предметов по метафоре через Groq и сборка
по названиям/карточкам библиотеки. Есть ручное редактирование, слои, L/S,
форматы холста, встроенные и пользовательские палитры, SVG-экспорт.
Композиции используют только исходные векторные объекты.

Стек: Python 3.12, FastAPI/Pydantic/Uvicorn, HTML/CSS/JavaScript и SVG DOM.
Проект запускается локально; инструкция и Windows-скрипт запуска есть в репозитории.
Для быстрого знакомства доступны три редактируемых примера без API-ключа.
Свободный запрос к ИИ требует ключа Groq проверяющего; личные ключи в исходники не включены.

В README собраны ссылки на короткую демонстрацию, архитектуру, соответствие ТЗ,
этапы разработки, использованные AI-инструменты и три примера SVG/JSON.
Для разработки применял Codex; модель не генерировала и не изменяла геометрию иллюстраций.

Отдельно описал трактовку ограничения на цветовую схему фона и технические границы решения.
