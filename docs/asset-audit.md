# Проверка библиотеки

Источник: два пользовательских экспорта Figma `Тестовое _ L_objects.zip` и
`Тестовое _ S_objects.zip`. Исходные SVG сохранены без изменений в `assets/source`.

## Подтверждено

- 10 предметов: книга, телефон, пазлы, монета, наушники, лампа, цветы,
  кошелёк, папка, ручка.
- Каждый представлен в L/S и главном/фоновом состоянии: 40 SVG.
- По три фона для L и S: фиолетовый, бирюзовый, персиковый.
- SVG прочитаны XML-парсером; растровые image, скрипты и foreignObject отсутствуют.
- Визуально проверены контактные листы обоих архивов: предметы, тени и фоны
  соответствуют предоставленным скриншотам на доступном масштабе.
- S содержит самостоятельные упрощённые варианты. Фоновые варианты S иногда
  сохраняют больше деталей, чем цветные. Это свойство исходников, не ошибка импорта.
- Габариты главного и фонового состояния каждого предмета совпадают внутри размера.

## Дополнительные файлы

Три `Group …` с прямоугольными образцами в каждом архиве — палитры.
Они сохранены для определения цветовых ролей, не включены в каталог предметов.
`Vector.svg` и `Vector-1.svg` в L — два фрагмента 17×24, один белый,
другой фиолетовый. Их точная принадлежность не установлена; они сохранены
в исходниках и не используются как самостоятельные предметы.

## Воспроизведение

`python scripts/prepare_assets.py` создаёт `assets/catalog.json`, проверяет
пары и записывает SHA-256 каждого используемого исходника.
Для контактных листов: установить Node.js и пакет `sharp`, затем
`node scripts/contact-sheet.cjs`. Контактные листы служат только проверке;
приложение должно использовать SVG, а не PNG.

## Правила для реализации

- Использовать исходную геометрию; преобразования применять к целой группе.
- Сохранять относительные размеры предметов посредством общего масштаба сцены.
- Не подменять S масштабированной версией L.
- Перекрашивать по цветовым ролям: фоновые цвета допустимы в предметах,
  цвета основных предметов не должны попадать в фон.
- Сохранять отдельные группы предметов в итоговом SVG.
- До сдачи проверить экспорт в векторном редакторе: текущая проверка
  относится к исходной библиотеке, а не к будущему экспорту конструктора.
