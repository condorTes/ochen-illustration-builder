# Конструктор иллюстраций «очень»

Локальный веб-сервис для сборки векторных композиций из предоставленной библиотеки.
Первая рабочая версия: выбор компонентов по названиям или карточкам,
автоматическая раскладка, три формата, варианты S/L и три палитры.
Доступны перемещение, поворот, смена состояния, дублирование, удаление,
порядок слоёв и векторный SVG-экспорт.

## Запуск (Python 3.12)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-lock.txt
python -m uvicorn app.main:app --reload
```

Открыть http://127.0.0.1:8000. Для macOS/Linux активация:
`source .venv/bin/activate`. Node.js для приложения не требуется.
Если активация недоступна, запускайте команды через
`.venv\Scripts\python.exe` вместо `python`.

`requirements-lock.txt` фиксирует проверенные версии зависимостей;
`requirements.txt` задаёт допустимые диапазоны для последующего обновления.
Пример экспорта, скачанный через интерфейс: `examples/learning.svg`.

Введите `Книга, лампа, наушники` или выберите карточки, затем нажмите
«Собрать композицию». Палитра сохраняет позиции; изменение формата,
детализации или схемы раскладки создаёт новую сцену из уникальных предметов
и сбрасывает ручные изменения. Текущая сцена хранится в памяти вкладки:
скачайте SVG перед обновлением страницы.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Проверяются сохранность исходников и контуров, уникальность SVG-id,
раскладка в границах холста и обработка неизвестных объектов.

## Библиотека

- `assets/source/L` и `assets/source/S`: исходные экспорты без изменения геометрии.
- `assets/catalog.json`: 10 предметов × 2 размера × 2 состояния и 6 фонов.
- `docs/asset-audit.md`: результаты проверки и ограничения.
- `scripts/prepare_assets.py`: воспроизводимая подготовка каталога (Python 3.10+,
  только стандартная библиотека).

```sh
python scripts/prepare_assets.py
```

## Следующие этапы

1. Разбор метафоры с ИИ и проверкой выбора по каталогу.
2. Загрузка пользовательской палитры по цветовым ролям.
3. Улучшение художественной композиции: текущая раскладка детерминирована
   и избегает перекрытий, но ещё не воспроизводит все приёмы референсов.
4. Проверка экспорта в Figma, финальная демонстрация и описание AI-инструментов.

Исходные иллюстрации предоставлены для тестового задания. Лицензия на их
дальнейшее использование этим репозиторием не предоставляется.
