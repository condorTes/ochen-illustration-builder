# Конструктор иллюстраций «очень»

Локальный веб-сервис для сборки векторных композиций из предоставленной библиотеки.
Первая рабочая версия: выбор компонентов по названиям или карточкам,
автоматическая раскладка, три формата, варианты S/L и три палитры.
Доступны перемещение, поворот, смена состояния, дублирование, удаление,
порядок слоёв и векторный SVG-экспорт.

## Запуск (Python 3.12)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-lock.txt
python -m uvicorn app.main:app --reload
```

Открыть http://127.0.0.1:8000. Для macOS/Linux активация:
`source .venv/bin/activate`. Node.js для приложения не требуется.
Если активация недоступна, запускайте команды через
`.venv\Scripts\python.exe` вместо `python`.

`requirements-lock.txt` фиксирует проверенные версии зависимостей;
`requirements.txt` задаёт допустимые диапазоны для последующего обновления.
Пример экспорта, скачанный через интерфейс: `examples/learning.svg`.

Введите `Книга, лампа, наушники` или выберите карточки, затем нажмите
«Собрать композицию». Смена формата и S/L сохраняет слои, дубликаты,
повороты и состояния. Центры предметов адаптируются к новому холсту,
масштаб остаётся общим для всех предметов. Смена схемы расположения
пересобирает сцену из уникальных предметов; её можно отменить.

Над холстом находятся отмена/повтор (до 60 состояний), очистка и сохранение
проекта в JSON. JSON можно открыть для дальнейшей работы; SVG служит итоговым
векторным экспортом. Последняя сцена автоматически сохраняется в localStorage
текущего браузера и восстанавливается после обновления. История отмены хранится
только до закрытия/обновления страницы. Секреты в проект и localStorage не записываются.

## Пользовательская палитра

Нажмите «Скачать образец», замените HEX-цвета и загрузите JSON кнопкой
«Загрузить палитру». Готовый пример — `examples/palette.json`.

```json
{
  "name": "Моя палитра",
  "background": ["#D7CDF5", "#AA9BF0", "#7864D7"],
  "objects": ["#F9ECB0", "#F9A3AA", "#FFE3E1"]
}
```

В каждой группе ровно три цвета. `background` заменяет три роли фоновой
палитры; эти цвета могут встречаться и в предметах. `objects` применяется
только к цветным предметам. Чёрные контуры и белые участки сохраняются.
Структура и декоративная геометрия выбранного фона не меняются.
Палитра сохраняется в JSON-проекте и применяется при SVG-экспорте.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Проверяются сохранность исходников и контуров, уникальность SVG-id,
раскладка в границах холста и обработка неизвестных объектов.

## Библиотека

- `assets/source/L` и `assets/source/S`: исходные экспорты без изменения геометрии.
- `assets/catalog.json`: 10 предметов × 2 размера × 2 состояния и 6 фонов.
- `docs/asset-audit.md`: результаты проверки и ограничения.
- `scripts/prepare_assets.py`: воспроизводимая подготовка каталога (Python 3.10+,
  только стандартная библиотека).

```sh
python scripts/prepare_assets.py
```

## Подбор по метафоре через Groq

Скопируйте `.env.example` в `.env` и вставьте свой `GROQ_API_KEY`.
Файл `.env` исключён из Git. Никаких дополнительных библиотек для подключения
не требуется. В интерфейсе выберите «По идее · ИИ», введите заголовок и нажмите
«Собрать композицию». Текст идеи и описания библиотеки отправляются в Groq;
SVG в Groq не передаются. Ключ доступен только Python-серверу.

Модель возвращает только идентификаторы предметов, роли и объяснение.
Сервер отвергает неизвестные объекты и неверную структуру ответа. Контуры
по-прежнему берутся исключительно из исходников. Без ключа доступен режим
«Из выбранных предметов»; ошибки ИИ не подменяются скрытым деморежимом.

По умолчанию модель `openai/gpt-oss-20b`, её можно изменить через `GROQ_MODEL`.
Результат повторной идеи кешируется на час в памяти процесса. Лимит приложения:
5 запросов в минуту и 40 в час на процесс. Это защита локальной демонстрации,
не замена авторизации публичного сервера. До публикации нужно добавить контроль
доступа и общий лимит для всех процессов. Квоты аккаунта Groq могут быть ниже.

Интеграция основана на https://console.groq.com/docs/openai.
